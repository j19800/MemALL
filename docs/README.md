## 四、维护约定

1. **新文档必须带状态行**：`> **文档状态**：现行 / 部分过时 / 历史留档 / 已被取代 — <一句话说明>`
2. **结论被代码超越时，改状态行，不要删文档**——推演过程本身有价值，但必须标明它不再是事实。
3. **同名系列只留一份"定稿"**：其余标 `已被取代`。
4. **分析完就转 ADR + 归档**：ADR 短、可推翻、带验证指向；叙事文长、易漂移。别让叙事文档代替 ADR。
5. **新文档要登记进本索引**，否则等于没写。
6. **一次性工作产物直接进 `archive/<年月>/`**，不要堆在 `docs/` 根目录或项目根目录。
