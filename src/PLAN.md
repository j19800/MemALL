# 实现未实现的功能计划

## 目标功能
1. 个性化排序（基于交互历史的学习排序模型）
2. Faceted search（便于结果探索）
3. 查询扩展与建议
4. 聚类组织结果
5. 可解释性：解释为何返回该结果
6. 基于当前任务/项目的上下文提升

## 实施阶段

### 阶段 1：基础设施
- 添加交互历史表（clicks、dwells等）或扩展现有表
- 添加查询扩展配置（同义词库）
- 添加特征重要性计算工具（用于可解释性）

### 阶段 2：Faceted search
- 在 retrieve 中添 facet_fields 参数
- 返回聚合计数（如 level、category 分布）
- 保持向后兼容

### 阶段 3：查询扩展与建议
- 在 unified_search 前加入查询扩展步骤
- 从配置读取同义词或使用最近热门查询
- 提供建议接口

### 阶段 4：聚类组织结果
- 在向量检索结果上做简单 K-means 聚类（可选）
- 返回簇标题和结果分组

### 阶段 5：可解释性
- 在 FTS5 中返回匹配词高亮
- 在向量检索中返回特征贡献度（简化版）
- 在结果中加入 explanation 字段

### 阶段 6：上下文提升
- 检索时读取最近的对话或活跃项目
- 对相关记忆增加上下文权重分数

### 阶段 7：个性化排序
- 记录点击、停止等交互（需前端配合，这里先预留接口）
- 训练简单的线性模型或使用在线学习
- 在排序阶段加入个性化权重

## 里程碑
- M1: 完成 Faceted search 和 查询扩展
- M2: 完成 可解释性 和 聚类
- M3: 完成 上下文提升 和 个性化排序（基础版）
